  1. Write the contract firstOne page that says what a record must look like: fields, types, allowed values, ranges and freshness. It was written before any code.
    2. 
      
  2. Enforce it with PydanticA BaseModel per record type, strict validation, and a CONTRACT category kept apart from MALFORMED.
    3. 
      
  3. Log every stepA structured logger with fixed fields. It has no place for note text, and masks anything that looks like a key.
    4. 
      
  4. Report every caseSix counts, so every flagged case lands in exactly one place. abstained is not failed.

  5. Check and measure the AIThe reply must have the right shape, allowed values and a quote that is in the note. One repair at most, then four separate measures.

Rebuild it

  
One batch, step by step

  
Each step depends on the one before it. Click the steps in the order the program runs them, first to last.

  

    

    

    

    

  

  
Why this order?Required files come first, because there is nothing to read without them. Each row is parsed and then checked against its contract, and the rejects are written to quarantine.csv before any gate can stop the run. The model is only asked after the batch has passed, the run report is written next, and summary.json is written last, because it means "finished". Every step also leaves a line in run.log.jsonl.

Which reply status, and which count?

  

  
Match the response to the problemA reply that cannot be read gets one repair. A reply whose values are wrong is never repaired, because asking again only invites a better-sounding invention. A model that honestly says "I cannot tell" has not failed.

The run report and the evaluation

  

  

    
You wantRemember

    
The six counts, in orderaccepted, quarantined, incomplete, suggested, abstained, failed

    
incompleteFlagged, but no note, so no model call

    
failedA call was made and the reply was INVALID_REPLY or UNAVAILABLE

    
FreshnessNewest shipment scan versus the batch date: FRESH, STALE (over 14 days) or NO_DATA

    
The four AI measuresstructural validity, category correct, grounded, abstention correct. Never blended into one

    
The two versionsThe eval set (eval- plus 8 characters of a hash) and the prompt version (v2)
